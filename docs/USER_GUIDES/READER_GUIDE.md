# Reader Guide

*For everyone who uses controlled information.*

## Finding the current document

Start at the DMS home page and use **Find a Current Document**. The default view shows **only**
current effective documents — you cannot accidentally open a superseded revision from it.

Three ways to find something:

| You know | Do this |
|---|---|
| The Document ID | Type it exactly into search. Exact-ID search is supported. |
| The process | Filter by Business Process or Business Function. |
| Roughly the title | Keyword search, then check the Document ID and Effective date in the results. |

Every result shows: Document ID, title, revision, lifecycle status, effective date, owner, document
type, business process and applicability. You should not need to know which site, library or folder
anything lives in.

## Reading the status badge

| Badge | Meaning |
|---|---|
| **Effective** | Current and authorised. Use this. |
| **Superseded** | Replaced. Do **not** use. A link to the replacement is shown. |
| **Withdrawn** | Removed from use with no replacement. Do **not** use. Contact Document Control. |

If you open an old bookmark and land on a superseded or withdrawn document, a prominent warning
appears with a link to the current replacement where one exists. Update your bookmark to the current
document.

## Why you should not save your own copy

A downloaded or printed copy is **uncontrolled**. It does not update when the document is revised, and
you have no way to know it went out of date. Every rendition carries a footer saying so.

Link to the DMS instead of attaching files to email. Notifications from the DMS always contain a link,
never an attachment, for exactly this reason.

## What you cannot see, and why

You cannot see draft versions. Drafts are work in progress and have not been reviewed or approved —
seeing one and acting on it is the failure the system exists to prevent. Once a draft is approved and
its effective date arrives, it becomes the current version automatically.

## Acknowledgements

If a document requires acknowledgement, you receive a task with a link to the exact revision. Your
response is recorded against that revision, with a timestamp.

Acknowledgement records that you confirmed you have read and understood the document. It is **not** a
competence or training certification.

## If something looks wrong

Report it to Document Control, especially:

- two versions of the same document both appear current
- a document you rely on has no owner or is long past its review date
- a link takes you somewhere unexpected

The first of these is the most serious problem the system can have; please report it immediately.

## Errors

Every error message tells you what happened, whether your work was saved, what to do, and a
correlation ID. Quote the correlation ID when you contact support — it links directly to the
diagnostic record.
